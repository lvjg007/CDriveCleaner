# Windows C 盘清理工具 — 设计文档

**日期：** 2026-07-30  
**项目路径：** `D:\workspace\tools\CDriveCleaner`  
**状态：** 已确认，首版已按计划实现（未自动提交 git）

## 1. 目标

做一个 **Windows 图形界面** 程序，帮助用户手动扫描并清理 C 盘中「非系统、可清」的占用空间。C 盘用着用着就满是核心痛点，因此覆盖面要尽可能广，但必须用预览、推荐标签和硬排除防止误删系统与个人重要文件。

### 1.1 已确认需求

| 项 | 决定 |
|---|---|
| 形态 | 图形界面（CustomTkinter），功能优先，界面极简 |
| 技术栈 | Python + CustomTkinter，PyInstaller 打包为 exe（目标机无需 Python） |
| 交互 | 人工点击「开始扫描」，不做定时任务 |
| 操作入口 | 扫描预览勾选 + 一键安全清理 + 深度清理 |
| 推荐 | 每项标注「建议删除 / 可选 / 不建议」及原因 |
| 删除方式 | 永久删除（不进回收站） |
| 隐私 | 日志仅本地，不上传网络 |
| 版本控制 | 未经用户明确要求不提交 git；不删除文件除非用户确认 |

### 1.2 非目标（首版不做）

- 定时自动清理、开机自启清理
- 系统托盘、多主题、复杂向导式 UI
- 激进清理 `WinSxS`、页面文件、休眠文件（默认关闭；首版可不实现开关）
- 云同步、远程管理

## 2. 方案选择

对比过三种路线后采用 **方案 1：模块化扫描器 + CustomTkinter**：

1. **模块化扫描器 + GUI（采用）** — 可扩展、误删可控、易打包  
2. 系统 cleanmgr 薄壳 — 太保守，难满足「尽可能腾空间」  
3. Electron + 脚本内核 — 包体大、过重  

## 3. 架构

四层分离：

```
界面层 (ui)          扫描按钮、列表、确认框、进度、结果摘要
    ↓
编排层 (app/orchestrator)   调度扫描、汇总、推荐、执行、取消
    ↓
扫描器层 (scanners)  Temp / Recycle / Browser / DevCache / LargeFiles / ...
    ↓
执行层 (cleaner)     永久删除、权限、跳过失败、写日志
```

### 3.1 统一结果模型

每个扫描条目至少包含：

- `id`：稳定标识  
- `category`：分类名  
- `path`：目标路径  
- `size_bytes`：预估大小  
- `risk`：`low` | `medium` | `high`  
- `recommendation`：`recommend` | `optional` | `not_recommended`  
- `reason`：一句话说明  
- `needs_admin`：是否需要管理员  
- `selected`：UI 勾选状态（由推荐规则初始化）

### 3.2 主流程

1. 启动 → 检测管理员权限与 C 盘空间  
2. 用户点击「开始扫描」  
3. 各扫描器**按顺序**执行并更新进度（首版不做并行，降低锁与占用冲突）  
4. 汇总列表：默认勾选「建议删除 + 低风险」  
5. 用户选择：一键安全清理 / 深度清理 / 清理勾选项  
6. 确认（永久删除警告；深度/高风险二次确认）  
7. 逐条删除 → 摘要 + 本地日志  

## 4. 清理分类与推荐规则

### 4.1 分类清单（首版）

| 分类 | 典型内容 | 默认推荐 |
|---|---|---|
| 系统临时文件 | `%TEMP%`、`C:\Windows\Temp` | 建议删除 |
| Windows 更新缓存 | `SoftwareDistribution\Download` 等 | 建议删除（常需管理员） |
| 回收站 | `$Recycle.Bin` | 建议删除 |
| 缩略图等缓存 | Thumbcache 等 | 建议删除 |
| 浏览器缓存 | Chrome/Edge/Firefox Cache（保留书签/密码相关目录） | 建议删除 |
| 开发工具缓存 | npm/yarn/pnpm、pip、Maven、Gradle、NuGet、编辑器缓存 | 建议删除（注明可能需重新下载） |
| 安装包残留 | 用户目录下大型 `.exe/.msi/.iso` 等 | 可选 |
| 大文件扫描 | C 盘超过阈值阈值（默认 200MB）的文件 | 不建议默认删，仅展示勾选 |
| 下载目录长期未访问 | 仅扫描「下载」文件夹内超过 90 天未访问的文件 | 不建议默认删，仅展示 |

说明：大文件扫描会跳过硬排除路径；可能较慢，进度条按已扫描分类/目录反馈。

### 4.2 推荐与入口映射

首版约定：`recommendation` 与默认 `risk` 成对出现（建议→低、可选→中、不建议→高）。一键/深度入口按 **recommendation** 判断，不以单独改 risk 绕过。

| 推荐 | 默认风险 | 一键安全 | 深度清理默认纳入 | 自定义勾选 |
|---|---|---|---|---|
| 建议删除 | 低 | 是（默认勾选） | 是 | 可改 |
| 可选 | 中 | 否 | 是（需二次确认） | 可改 |
| 不建议 | 高 | 否 | 否 | 可勾选 + 二次确认 |

规则优先级：**硬排除 > 推荐标签 > 用户勾选**。硬排除路径永不进入可删列表。

### 4.3 硬排除（必须）

- `C:\Windows\System32`、`C:\Windows\SysWOW64`、`Boot` 相关  
- `WinSxS` 不做激进清理  
- 用户 `Documents` / `Desktop` / `Pictures` / `Videos` 不做自动「建议删除」  
- 疑似源码/项目目录（存在 `.git`、`package.json`、`.sln`、`pyproject.toml` 等）不进「建议删除」  
- 删除前再次校验硬排除，防止路径拼接绕过  

## 5. 界面（极简）

自上而下单页：

1. **状态区**：C 盘总量/已用/可用；是否管理员  
2. **操作区**：`开始扫描`；扫描后：`一键安全清理`、`深度清理`、`清理勾选项`；进度条文案  
3. **结果表**：勾选 | 分类 | 大小 | 推荐 | 风险 | 原因  
4. **底部**：已选合计大小；完成后成功/失败数、释放空间、日志路径  

不做多页向导、动画、托盘、主题。

## 6. 删除、权限、日志、错误

### 6.1 删除

- 永久删除（不进回收站）  
- 执行前确认框明确「不可恢复」  
- 一键安全：确认一次  
- 深度清理或包含高风险项：二次确认  
- 逐条执行：单项失败则记录并继续  

### 6.2 权限

- 检测管理员；非管理员可扫用户空间，系统项标「需管理员」  
- 提示可提权重启，不强制  
- 无权限失败写入日志，不崩溃  

### 6.3 日志

- 目录：程序旁 `logs/`  
- 内容：时间、操作类型、路径、大小、成功/失败、错误信息  
- 仅本地，不上传  

### 6.4 其它

- 路径不存在、文件占用：跳过并记录  
- 扫描/删除支持取消；已删除不回滚

## 9. 测试要点

- 扫描：各分类能出结果与大小；硬排除路径不出现在可删列表  
- 推荐：默认勾选仅「建议 + 低风险」  
- 一键安全 / 深度 / 自定义三条路径行为符合映射表  
- 永久删除确认文案正确；取消不删  
- 无管理员时系统项标记正确且不崩溃  
- 文件占用/权限错误跳过并写日志  
- 打包后的 exe 在无 Python 机器可启动（实现后期验证）
